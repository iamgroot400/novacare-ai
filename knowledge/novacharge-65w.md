# NovaCharge 65W Troubleshooting

Warranty on NovaCharge is **6 months** (shorter than standard electronics).

## Not fast charging / only trickle charging

1. Use a certified **USB-C to USB-C** cable rated for 60W or higher. Many bundled
   cables are limited to 3A / 20W.
2. Use a single port. When both ports are in use the charger splits power
   (45W + 18W), so a laptop on one port will charge slower.
3. Check the device supports USB-C Power Delivery. Some laptops only accept PD at
   specific wattages.
4. Try another wall socket — low mains voltage during load-shedding reduces output.

If a known-good PD cable on a single port still only delivers ~5W, the charger is
likely faulty. NovaCharge connectivity/charging failures not caused by damage are
covered for 6 months — check eligibility and offer a support ticket.

## Charger is hot

GaN chargers run warm under full load; too hot to hold comfortably for several
seconds is not normal. Unplug it, let it cool, and if it overheats again at moderate
load, stop using it and open a support ticket.

## Buzzing / coil whine

A faint whine under load is common. A loud buzz, or any smell of burning, means stop
using it immediately and contact support.

## One port dead

Test each port with the same cable and device. If one port never works, that is a
hardware fault within the 6-month window — offer a support ticket.
