# NovaKeys Mechanical & Compact Troubleshooting

Applies to **NovaKeys Mechanical** (P006) and **NovaKeys Compact** (P019).

## Keyboard not connecting wirelessly

1. Charge over USB-C for 15 minutes.
2. Set the connection switch to **BT** (not USB / 2.4G).
3. Hold `Fn + 1` for 3 seconds to enter pairing on slot 1; the slot LED blinks.
4. On the computer, remove any old "NovaKeys" entry and pair fresh.
5. For multi-device use, `Fn + 1/2/3` switches between paired hosts.

## Some keys not registering

- Hot-swappable switches can work loose in transit. Power off, gently press each
  switch fully into its socket, or reseat the switch with the included puller.
- Check the switch pins are straight before reinserting.
- Try the key in both wired and wireless mode to isolate the fault.

## Double typing / chatter

1. Update firmware with the NovaKeys configurator.
2. Increase the debounce setting to 8 ms.
3. If a specific switch still chatters, swap it with a spare — this is why the board
   is hot-swappable. Persistent multi-key chatter after a firmware update is covered
   by warranty; offer a support ticket.

## RGB not working

- Cycle lighting modes with `Fn + \`.
- Raise brightness with `Fn + Up`.
- In battery-saver mode the backlight dims automatically; plug in USB-C to restore.

## Wrong characters typed

Toggle the OS layout switch: `Fn + Ctrl + W` for Windows, `Fn + Ctrl + M` for macOS.
